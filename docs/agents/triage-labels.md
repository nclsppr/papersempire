# Triage labels

The skills use five canonical roles. This table maps them to labels in GitHub Issues.

| Role in `mattpocock/skills` | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for details from its author |
| `ready-for-agent` | `ready-for-agent` | The issue is precise enough for an autonomous agent |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation |
| `wontfix` | `wontfix` | The issue will not be handled |

When a skill names a role, use the corresponding GitHub label in this table. Change only the second column if the repository adopts another label vocabulary.
