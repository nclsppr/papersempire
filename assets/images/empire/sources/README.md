# Empire — fond de rivière

- Source générée : `riverside-campus.png`, 1536 × 1024 pixels.
- Génération : OpenAI, 7 septembre 2026.
- Brief de direction : campus industriel miniature ivoire, organisé autour
  d’une rivière, sans bâtiments représentant des unités possédées par le joueur.
- Dérivé de production : `../riverside-campus.webp`, 1536 × 1024 pixels.

Le décor fournit le sol et l’ambiance. Les unités possédées, leurs quantités et
leur croissance sont projetées séparément à partir de l’état du jeu. Les douze
illustrations de bâtiments existantes sont réutilisées ; ce dossier ne contient
qu’une nouvelle source générée.

Le PNG et cette note restent dans le dépôt pour la provenance. Les assemblages
Web et iOS excluent les répertoires `sources/` et embarquent le dérivé WebP.
